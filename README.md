# 玻璃收纳 GlassBox

一个很轻的 Windows 11 桌面整理工具：桌面上的文件自动按类型收进屏幕顶部的「流光胶囊」，鼠标碰一下就展开，像灵动岛一样。

- **轻**：内存约 10–15 MB，空闲时 CPU 为 0，启动不到 1 秒
- **安全**：只记录文件的“引用”，**从来不移动、不删除你的文件**（自己点“丢进回收站”的除外，而且 5 秒内可以撤销）
- **解压即用**：自带运行库，不用安装 .NET 或任何东西

## 下载和使用

1. 到 [Releases](../../releases) 下载 `GlassBox-v*-win-x64.zip`
2. 解压到一个固定的位置（比如 `D:\Apps\玻璃收纳`）
3. 双击 `GlassBox.exe`

第一次打开时，Windows 可能提示“Windows 已保护你的电脑”（程序没有付费签名）：点 **更多信息 → 仍要运行**。

打开后：
- 鼠标移到**屏幕顶部中间**的胶囊上就会展开，移开自动收起
- **连按两下 Ctrl**：在任何地方呼出胶囊（全屏游戏时不响应）
- 胶囊里点 ⚙ 打开设置；右下角托盘图标里还有更多选项

## 功能

界面有中文和 English 两种语言：⚙ → 桌面与系统 →「语言 / Language」，或托盘菜单 设置 → 语言 / Language，切换马上生效。新装时跟着 Windows 的显示语言选。

**桌面**
- 新文件自动按类型分类（快捷方式、文件夹、文档、程序和安装包、压缩包、图片影音……），分类可以拖着调顺序
- 双击桌面空白处隐藏/显示；可以隐藏系统桌面图标
- 在桌面（或打开的胶囊）上按 Ctrl+V：复制的文件存一份到桌面，复制的图片存成 PNG，自动收进分类；只新建、不覆盖（默认关）
- 顶部胶囊自动隐藏；玻璃会透出背后的颜色（支持动态壁纸）
- Windows 任务栏透明/磨砂（仅 Windows 11 22H2/23H2）

**文件面板**
- 「常用」（按打开次数）、「最近下载」、「图像」（所有截图）自动整理
- 搜索支持拼音首字母（`wx` → 微信）
- 空格预览，Enter 打开；拖图标调顺序、拖到别的分类、拖到别的程序里
- 把文件拖到右下角“丢进回收站”，5 秒内可撤销（默认关，在设置里打开）

**音乐**
- 胶囊上显示正在播放的歌（支持浏览器、Spotify 等），封面会像唱片一样转
- 音乐卡片：进度条、上一首/下一首、单独调这个程序的音量、定时暂停
- 锁住卡片：**双击卡片**（或点右上角的小锁）让它一直开着、不自动收起，边上会有一圈慢慢呼吸的光；再双击解开，歌停了自动解开
- 在卡片上滚滚轮调音量，封面上浮出大数字；卡片上显示现在从耳机还是音箱出声
- 卡片上右键：锁住、换一个版本的歌词、手动搜索歌词、歌词提早/延后 0.5 秒
- 同步歌词（默认关；打开后会把歌名、歌手发给 [lrclib.net](https://lrclib.net) 查询）：上一句、当前、下一句一起显示，带阴影和柔光，唱到哪亮到哪；还可以收起时在胶囊上一句句滚动

以下都默认关，在 ⚙ → 音乐 / 歌词与广告 里打开：
- 卡片背景用模糊、慢慢流动的封面
- 封面换成唱片机：封面做黑胶中间的标签，放歌时唱臂落下、唱片转；暂停时唱片慢慢停、唱臂抬回去（默认关）
- 把卡片往下拖出来，变成浮在桌面上的小播放器（拖回屏幕顶部收回胶囊）
- 放歌时连按两下 Ctrl 打开并锁住卡片
- 点输出设备在音箱和耳机之间切换（会改 Windows 的默认输出设备）
- 蓝牙耳机电量：只读系统里已有的电量
- 也从网易云音乐找歌词：中文歌多，很多是逐字亮的（非官方接口，可能哪天失效；会把歌名、歌手发给网易云）
- 外文歌的歌词下面显示中文翻译（网易云带的；默认关）
- YouTube 放久了问“仍在观看吗？”时自动点继续（要装自带的 Edge 扩展；默认关）
- YouTube 广告出现“跳过”按钮时，胶囊滑下来，点一下就跳过（或者自动跳过）。按的是 YouTube 自己的跳过按钮，不屏蔽广告、不动鼠标
  - **推荐装自带的 Edge 扩展**（在程序文件夹的 `edge-extension` 里，⚙ → 歌词与广告 → 「怎么装…」会一步步带你装）：YouTube 在后台标签页、Edge 最小化时也能用。扩展只在 YouTube 上工作，只和本机的玻璃收纳通信（127.0.0.1:48613，只认浏览器扩展的请求）
  - 不装扩展也能用，但 YouTube 要是浏览器窗口正在显示的标签页，窗口不能最小化（被别的窗口挡着没关系）

**动效与专注**（都默认关，在胶囊里点 ⚙ → 动效）
- 天色光：胶囊跟着早晚变色，白天像太阳从左走到右，夜里有几颗星
- 插上充电器时：电池一格格涨上去，一道绿光扫过胶囊
- 截图像飞进胶囊：刚截的图在屏幕中间定格一下，再缩小飞进胶囊
- 番茄钟：面板上多一个计时按钮；专注时胶囊只显示倒计时，提示先攒着、动画停下来，结束后休息 5 分钟

## 卸载

在托盘图标 → 设置 → **卸载玻璃收纳…**（或者双击文件夹里的 `卸载玻璃收纳.cmd`）。

它会还原桌面图标和任务栏、关掉开机自启，再问你要不要删除设置。之后直接删掉程序文件夹就干净了。

> ⚠ 请不要不卸载就直接删文件夹：如果开了“隐藏系统桌面图标”，图标会一直藏着
> （可以在桌面右键 → 查看 → 勾选“显示桌面图标”找回来）。

## 数据放在哪里

| 位置 | 内容 |
|---|---|
| `%APPDATA%\GlassBox` | 设置、分类、常用记录、日志 |
| `%LOCALAPPDATA%\GlassBox` | 歌词缓存、任务栏助手 |

全部只在你的电脑上。唯一会联网的是“同步歌词”（默认关；另外打开“网易云”的话也会问网易云音乐）。

## 从源码编译

需要 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)。任务栏透明另外需要 Visual Studio（或 Build Tools）的“使用 C++ 的桌面开发”，没有也能编译，只是这个功能用不了。

```powershell
GlassTap\build.cmd                                         # 可选：任务栏透明用的 DLL
dotnet build -c Release                                    # 编译
powershell -ExecutionPolicy Bypass -File release.ps1       # 打包成 out\GlassBox-v*-win-x64.zip
```

## 系统要求

Windows 11 x64（在 23H2 上开发和测试）。
